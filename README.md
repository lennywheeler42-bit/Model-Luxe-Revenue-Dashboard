# Model Luxe Media Revenue Dashboard

This is a Vercel-ready React/Vite application.

## Run it locally

1. Install Node.js 18 or newer.
2. Open Terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.

## Deploy to Vercel

Upload/import this complete project folder, not only `App.tsx`. Vercel will use
the included build settings automatically.

## Data storage

Dashboard data is saved automatically in the browser's local storage. It stays
on the same browser and device, but it is not synchronized between team members.
A shared database can be connected later when team-wide live data is needed.
